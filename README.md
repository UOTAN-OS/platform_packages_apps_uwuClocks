# uwuClocks

## 原 uwuAOSP 项目说明

`uwuClocks` 是 uwuAOSP 的 SystemUI 时钟插件，提供动态配色的日期优先时钟和横向大数字时钟。

源项目：[uwuAOSP/platform_packages_apps_uwuClocks](https://github.com/uwuAOSP/platform_packages_apps_uwuClocks)

## UotanOS 集成

- 保留 `uwuClock`、`org.uwuaosp.clock`、uwu 类名、资源和时钟 ID。
- UotanOS 仅调整用户可见的平台品牌，组件技术标识保持不变。
